🍽️ Restaurant Web Page

This is a simple **restaurant website** built using only HTML.  
It showcases a basic structure of a modern restaurant page without using CSS or JavaScript.



📌 Features

- 🏠 Home section with About Us message  
- 📖 Menu section displaying food items  
- 📍 Contact / location details  
- 🔗 Navigation using semantic HTML 
- 📏 Tables 





🎯 Purpose

This project was created to:
- Practice **semantic HTML structure** and **Tables**
- Understand how to organize a web page without styling
- Build a foundation for future projects using CSS and JavaScript

- Footer
